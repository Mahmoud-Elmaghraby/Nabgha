# ADR-0005: النماذج أ/ب/ج/د بخلط ثابت وقت الطباعة

- **الحالة:** معتمد
- **التاريخ:** 2026-11-22

## السياق
المدرس عايز نماذج مختلفة من نفس الامتحان عشان يقلّل الغش، ولكل نموذج نموذج إجابة بيطابقه.

## القرار
- مابنخزّنش النماذج.
- وقت الطباعة: `applyVersion(items, examId, v)` بخلط ثابت بـ seed = `examId:v` (mulberry32 + FNV).
- النموذج أ = الترتيب الأصلي.
- الأسئلة بتتخلط جوّه كل قسم، والأقسام ثابتة في مكانها. واختيارات الاختياري بتتخلط، وأي اختيار زي "كل ما سبق" بيفضل آخر واحد.

## النتائج
- ✅ مفيش جداول جديدة، ونموذج الإجابة بيطابق دايماً، ونفس النموذج بيطلع زي ما هو في أي وقت.
- ⚠️ لو الامتحان اتعدّل بعد ما اتطبع، النماذج هتتغيّر. اطبع بعد ما تقفل الأسئلة.
- ⚠️ الربط بالدرجات مش بيعرف كل طالب أخد أنهي نموذج، ومش محتاجه دلوقتي.
