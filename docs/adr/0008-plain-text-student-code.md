# ADR-0008: كود الطالب نص عادي في كل الأكواد المطبوعة

- **الحالة:** معتمد
- **التاريخ:** 2026-11-23

## السياق
السكانر بيكتب كأنه كيبورد. نافذة "QR الطالب" كانت بتطلع JSON فيه `{ } " :`، والرموز دي بتبوظ تماماً لو الكيبورد عربي. والليبلات والكروت كانوا بيستخدموا نص عادي، فكان فيه شكلين في البرنامج (BAR-002).

## القرار
- أي QR أو باركود = `studentCode` (`STU-00012`) كنص عادي.
- السيرفر بيقبل الأشكال القديمة كلها (JSON، كيبورد عربي، حروف صغيرة)، ويقبل كمان `qr_code` السري.

## النتائج
- ✅ بيشتغل مع أي لغة كيبورد، والكروت القديمة لسه شغالة.
- ⚠️ الكود المتسلسل قابل للتخمين، وده خطر التحضير بالنيابة. الحل (كروت بالكود السري) مؤجّل لمراجعة الكارت مع المالك، والبنية التحتية جاهزة.
