# ADR-0006: خط Cairo مضمّن في الـ PDF ومفيش أي طلبات شبكة

- **الحالة:** معتمد
- **التاريخ:** 2026-11-22

## السياق
PDF الامتحان كان بيحمّل خط من Google Fonts، فبيفشل أو بيطلع بخط تاني على الديسكتوب لو مفيش إنترنت. وكمان HTML الامتحان كان بيتبني من غير escaping (EX-002، EX-004).

## القرار
- خط Cairo (رخصة OFL)، العربي واللاتيني، متضمّن base64 في `embedded-cairo.font.ts` (حوالي 86KB).
- `PdfExportService.renderHtml()` بتمنع أي request غير `data:`، والصور بتتضمّن data URLs.

## النتائج
- ✅ PDF عربي سليم أوفلاين، وأمان ضد حقن HTML أو أي طلب شبكة.
- ⚠️ الـ bundle بتاع الـ API زاد حوالي 115KB.
- لاحقاً: التقارير لسه بتستخدم Arial وTahoma. ممكن تتحوّل لنفس الخط.
