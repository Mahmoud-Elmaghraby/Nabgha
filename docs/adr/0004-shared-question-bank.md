# ADR-0004: بنك الأسئلة مشترك على مستوى الحساب

- **الحالة:** معتمد (قرار المالك)
- **التاريخ:** 2026-11-22

## السياق
البنك والامتحانات كانوا متفلترين بالمستخدم اللي عامل الطلب (`teacher_id = req.user.sub`)، فالمساعد مكانش بيشوف أسئلة المدرس (EX-001). محمود قال: "انا دلوقتي ببيع لمدرس… ممكن يكون عنده اكتر من ماده… لحد الان مشتغلتش مع مراكز خارجية".

## القرار
- البنك والامتحانات مشتركين على مستوى الحساب كله (الـ tenant).
- `teacher_id` بيتسجّل كمنشئ بس.
- الفصل بين المواد والمراحل والوحدات بالفلاتر (`subject_id`، `grade`، `tags`).

## النتائج
- ✅ المدرس ومساعدينه بيشوفوا نفس البنك.
- ⚠️ لو اشتغلنا مع سنتر فيه مدرسين كتير مستقلين، هنحتاج نطاق للبنك: لكل مدرس، أو مشترك، أو مشترك بين مدرسين معيّنين. ده هيبقى ADR جديد.
